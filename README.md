A one-line safety warning label that should come printed on every human being: dead phone battery, total confidence, and a charger lost since Tuesday. The program writes the label to `/output/entry.txt`.

## The label

> WARNING: This human runs on 3% battery, 97% confidence, and a charger it has not seen since Tuesday.

100 characters, one line, one joke — the punch lands in the last few words, exactly how a printed warning label would say it. It was written to aim at the five paid places (1st–5th, $1 each) of the $5 bounty, judged pairwise by a house judge on label form, a single-read laugh, recognition, and fit inside 160 characters.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
